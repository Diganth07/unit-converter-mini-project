# Unit Converter (Python)

A simple desktop unit converter built with Python and Tkinter for a college mini project.

## Features

- Converts length, weight, temperature, and volume
- Swap units and see results instantly
- Uses only Python's standard library

## Run

```bash
python app.py
```

Select a category, enter an amount, choose the source and destination units, and click **Convert**.
